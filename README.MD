# Andrew's Garage 🚗

Modern, responsive landing page for an auto repair shop, built with custom frontend tools.

🌐 **Live Demo:** [https://andrewdreamer13.github.io/andrews-garage/](https://andrewdreamer13.github.io/andrews-garage/)

## 🚀 Tech Stack

* **Markup:** HTML5, Semantic Elements, BEM methodology
* **Styles:** SCSS (Sass), Flexbox, CSS Grid, Custom Media Queries
* **Build Tool:** Vite (`static-sites-vite-starter`)
* **JavaScript (ES6+):** Modular architecture, custom interactive components
* **Libraries & Plugins:**
  * **Swiper.js** — Responsive sliders and carousels
  * **Mapbox GL JS** — Interactive location map with custom markers
  * **Flatpickr** — Lightweight and powerful datetime picker for booking/appointments
  * **Web3Forms** — Backend-free contact and booking form submission handling
  * **GSAP** — Smooth animations and scroll triggers
* **Optimization:** WebP images, SVG sprites, automated asset handling

## ✨ Features

* Fully responsive layout tailored for mobile, tablet, and desktop devices.
* Interactive services and works sections powered by Swiper.
* Embedded Mapbox integration for easy navigation to the garage.
* Functional appointment booking with Flatpickr date selection and Web3Forms integration.
* Clean, lightweight codebase without heavy CMS overhead.
* Complete Open Graph meta tags configuration for social media and messengers preview.
